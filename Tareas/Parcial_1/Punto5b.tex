\vspace{2.5em}\textbf{b)} Si $B$ es compacto y $p^{-1}(b)$ es finito, para todo $b\in B$, entonces $E$ es compacto.
\begin{proof}       
   Supongamos que $B$ es compacto. Sea $\mathcal{A}=\{A_i\}_{i\in I}$ un cubrimiento abierto cualquiera de $E$. Para cada $b\in B$ llamemos $U_b$ a su vecindad regularmente cubierta por $p$, y $\{V_{b,\alpha}\}_{\alpha\in I_b}$ a la partición de $p^{-1}(U_b)$ en rebanadas.\\\\ 
   Dados $b\in B$ y $\alpha\in I_b$ cualesquiera, se tiene que $p|_{V_{b,\alpha}}:V_{b,\alpha}\to U_b$ es en particular biyectiva, luego existe un único $b^\bullet_\alpha\in V_{b,\alpha}$ tal que $p|_{V_{b,\alpha}}(b^\bullet_\alpha)=b$. De esta forma, la asignación $\alpha\mapsto b^\bullet_\alpha$ es una biyección entre $I_b$ y $\{b^\bullet_\alpha\}_{\alpha\in I_b}$ pues, además de ser claramente sobreyectiva, es inyectiva, pues dados $\alpha,\alpha'\in I_b$ con $\alpha\neq\alpha'$ entonces $V_{b,\alpha}\cap V_{b,\alpha'}=\emptyset$, lo que implica $b^\bullet_\alpha\neq b^\bullet_{\alpha'}$. Ahora bien, $p(b^\bullet_\alpha)=b$ para cada $\alpha\in I_b$, luego $b^\bullet_\alpha\in p^{-1}(b)$ y $\{b^\bullet_\alpha\}_{\alpha\in I_b}\subseteq p^{-1}(b)$. Como $p^{-1}(b)$ es finito, entonces $\{b^\bullet_\alpha\}_{\alpha\in I_b}$ es finito, lo cual implica que $I_b$ es finito. Como $b^\bullet_\alpha\in E$, existe $i_{b,\alpha}\in I$ tal que $b^\bullet_\alpha\in A_{i_{b,\alpha}}$. Notemos que $I_b\ne \emptyset$, pues, como $p$ es sobreyectiva y $U_b\ne\emptyset$, entonces $\bigsqcup_{\alpha\in I_b}V_{b,\alpha}=p^{-1}(U_b)\ne \emptyset$. Tomemos entonces $U_b^*=\bigcap_{\alpha\in I_b}p(V_{b,\alpha}\cap A_{i_{b,\alpha}})$. Para cada $\alpha\in I_b$ se tiene que $p|_{V_{b,\alpha}}$ es en particular una función de $V_{b,\alpha}$ en $U_b$, de modo que $p\left( V_{b,\alpha}\cap A_{i_{b,\alpha}}\right)=p|_{V_{b,\alpha}}\left( V_{b,\alpha} \cap A_{i_{b,\alpha}}\right)\subseteq U_b$; por tanto $U_b^*\subseteq U_b$. Ahora, para cada $\alpha\in I_b$ se tiene $V_{b,\alpha}\subseteqab E$ y $A_{i_{b,\alpha}}\subseteqab E$, luego $V_{b,\alpha}\cap A_{i_{b,\alpha}}\subseteqab E$. Como $p$ es una función recubridora entonces $p$ es abierta, luego $p(V_{b,\alpha}\cap A_{i_{b,\alpha}})\subseteqab B$. Como $I_b$ es finito, se sigue que $U_b^*\subseteqab B$. Además, para cada $\alpha\in I_b$ se tiene $b^\bullet_\alpha\in V_{b,\alpha}\cap A_{i_{b,\alpha}}$, luego $b=p(b^\bullet_\alpha)\in p(V_{b,\alpha}\cap A_{i_{b,\alpha}})$ y $b\in U_b^*$. De esta manera, $\{U_b^*\}_{b\in B}$ es un cubrimiento abierto del espacio compacto $B$, de modo que existen $b_1,\dots,b_n\in B$, con $n\in\mathbb{Z}^+$, tales que $\{U_{b_j}^*\}_{j=1}^{n}$ cubre a $B$.\\\\
   Veamos que $\mathcal{A}'=\bigcup_{j=1}^{n}\{A_{i_{b_j,\alpha}}\}_{\alpha\in I_{b_j}}$ cubre a $E$. Sea $e\in E$ cualquiera. Tenemos $p(e)\in U_{b_k}^*=\bigcap_{\alpha\in I_{b_k}}p(V_{b_k,\alpha}\cap A_{i_{b_k,\alpha}})$ para algún $k\in\{1,\dots,n\}$, luego $e\in p^{-1}(U_{b_k}^*)$. Como $U^*_{b_k}\subseteq U_{b_k}$ entonces $p^{-1}\left( U^*_{b_k}\right)\subseteq p^{-1}\left( U_{b_k}\right)=\bigsqcup _{\alpha\in I_{b_k}}V_{b_k,\alpha}$, así que $e\in \bigsqcup _{\alpha\in{I_{b_k}}}V_{b_k,\alpha}$, con lo cual existe $\beta\in I_{b_k}$ tal que $e\in V_{b_k,\beta}$. Tenemos $p(e)\in p(V_{b_k,\beta}\cap A_{i_{b_k,\beta}})$, luego $p(e)=p(e')$ para algún $e'\in V_{b_k,\beta}\cap A_{i_{b_k,\beta}}$. Así, $p|_{V_{b_k,\beta}}(e)=p|_{V_{b_k,\beta}}(e')$. Como $p|_{V_{b_k,\beta}}$ es inyectiva, tenemos $e=e'$ y $e\in V_{b_k,\beta}\cap A_{i_{b_k,\beta}}$. Entonces $e\in A_{i_{b_k,\beta}}$, y como $\beta\in I_{b_k}$ con $k\in\{1,\dots,n\}$, entonces $A_{i_{b_k,\beta}}\in\mathcal{A}'$. Por tanto $e\in\bigcup\mathcal{A}'$. De esta forma, $\mathcal{A}'$ cubre $E$. Pero $I_{b_j}$ es finito para cada $j\in\{1,\dots,n\}$, así que $\mathcal{A}'$ es finito, y además $\mathcal{A}'\subseteq\mathcal{A}$, es decir que $\mathcal{A}'$ es un subcubrimiento finito de $\mathcal{A}$. Por tanto $E$ es compacto.
\end{proof}\clearpage
